# Student Performance Analyzer 📊

A Python project that analyzes student marks and generates individual performance reports and a class summary.

## Features

- Calculate total and average marks
- Assign grades based on average marks
- Find highest and lowest marks
- Check subject-wise pass/fail status
- Generate reports for multiple students
- Identify the class topper
- Summarize class performance, including passes, failures, and class average

## Technologies Used

- Python 3

- Visual Studio Code

## How to Run

1. Install Python 3.
2. Clone the repository:

   ```bash
   git clone https://github.com/shailee18-blip/student-performance-analyzer.git
   ```

3. Enter the project folder:

   ```bash
   cd student-performance-analyzer
   ```

4. Run the program:

   ```bash
   python main.py
   ```

## Grading Rules

| Average Marks | Grade |
|---|---|
| 90 and above | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 40–59.99 | D |
| Below 40 | Fail |

The project considers a student to have passed only if every subject has at least 35 marks. These are example rules and can be customized.
