# Student Performance Analyzer 📊

A beginner-friendly Python project that analyzes student marks and generates individual performance reports along with a class summary.

## ✨ Features

- **Total Marks:** Calculates the total marks obtained by each student.
- **Average Marks:** Computes the average marks across subjects.
- **Grade Calculation:** Assigns grades based on average marks.
- **Highest and Lowest Marks:** Identifies the highest and lowest subject scores.
- **Pass/Fail Status:** Checks whether students meet the subject-wise passing criteria.
- **Multiple Student Reports:** Processes and displays reports for multiple students.
- **Class Topper:** Identifies the student with the highest average marks.
- **Class Summary:** Displays the total number of students, passes, failures, and overall class average.

## 📌 Grading Rules

The project uses the following example grading scale:

| Average Marks | Grade |
|---|---|
| 90 and above | A+ |
| 80–89.99 | A |
| 70–79.99 | B |
| 60–69.99 | C |
| 40–59.99 | D |
| Below 40 | Fail |

A student passes only if they obtain at least 35 marks in every subject. These are simplified project rules and can be adjusted to match an institution's grading policy.
